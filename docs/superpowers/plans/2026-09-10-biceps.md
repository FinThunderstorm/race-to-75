# Biceps circumference implementation plan

**Goal:** Add a Biceps view and manual, owner-managed circumference readings.

**Design:** Store dated centimetre readings in a separate `biceps_measurement`
table. Share them through the existing race/radiator response. Reuse the chart's
weekly/daily aggregation, stable participant colors, and three-month window.
Show current circumference and change without a goal or weight-loss badges.
Settings contains an authenticated add form and own-reading deletion list.
The mode selector, automatic rotation, sample data and settings return link all
support `mode=biceps`. Existing English UI labels remain English.

**Validation:** Accept dates through today (UTC), circumference 1–100 cm with at
most one decimal. These are input bounds, not health guidance. Reject extra
fields including user IDs; derive ownership from the session. Multiple readings
on a day are allowed and averaged. Users correct mistakes by deleting and adding.
